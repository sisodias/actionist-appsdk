## Current decisions

- Actionist is a semi-custom software assembly operating system, not a general Lovable clone.
- Repositories are source containers, not the universal reusable unit.
- Reuse shapes include intact service, embedded module, transplant, extracted package, adapter, generated pattern, template and custom delta.
- Postgres is the default for new owned transactional data, not a universal block invariant.
- The existing Block Contract should be separated into capability, packaging, host, binding, qualification, registry and release records.
- The old fixed five-area shell is an unproven archetype hypothesis.
