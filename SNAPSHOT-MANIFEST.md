# Actionist research and prototype snapshot

Snapshot date: 2026-08-28

This branch contains the durable Action Model project state after Sprint 1 and Sprint 2 convergence and the first contract-only implementation loop:

- canonical project and operator documentation;
- the consolidated knowledge spine;
- product and technical architecture;
- historical research receipts, Sprint 1 and Sprint 2 convergence packets, and current workstream contracts;
- the static system-map and task-graph site;
- the 24-record Framework Registry and repository Value Matrix contract;
- the AFFiNE and Teable v0.1 prototype block packages, including their explicit qualification holds;
- the deterministic AFFiNE/Teable/Chatwoot contract-only solver pilot and refusal receipts;
- the Program Driver task graph and the read-only multi-repository publication topology;
- non-secret client context.

The following are intentionally excluded:

- local runtime, browser, Wrangler and agent state;
- the nested checkout itself;
- generated dependency/build directories;
- the raw WhatsApp export containing an exposed credential;
- the external multi-gigabyte Great Library and 21st.dev payloads, which are referenced by manifests and should be linked as separate repositories or immutable object-store assets;
- donor application source and runtimes, which remain separately owned and pinned by identity rather than copied into this snapshot.

This snapshot is an index and evidence projection, not a production release. The included blocks remain `NOT_QUALIFIED` and `NOT_ADMITTED`; no deployment or client-data execution is claimed.

## Portability boundary

The AFFiNE, Teable and Chatwoot contract packets preserve content-hashed references to evidence in separate SISOCRM, Fahmy and Bykonz estates. Those external/private estates are intentionally not copied into this client index. Framework, system-map, Block Hub, knowledge-spine and Program Driver verification runs locally in this snapshot. Block and three-candidate solver receipts were independently verified in the canonical SISO workspace before publication; rerunning their full evidence-path checks from an isolated clone requires resolving the external evidence locators through the future repository/Great Library index.
