01 / The synthesis

What the research actually says

Read this before diving into vendor names.

The central thesis

The opportunity is not another prompt-to-app clone. It is a governed loop that turns internet code and agent actions into a safe, evidence-backed client outcome.

Commercial builders have made generation fast. The missing layer is controlled composition: provenance, license fit, action authority, recovery, review, and a repeatable path from a semi-custom brief to a deployable vertical system.

Decision posture

  • Keep the platform map broad; use it to define capability boundaries.
  • Run OSS discovery per vertical and reusable capability, not as one undifferentiated pile.
  • Treat every block as an admitted artifact with receipts, not a promising GitHub URL.
  • Do not call a build authorized until the synthesis gates close.
