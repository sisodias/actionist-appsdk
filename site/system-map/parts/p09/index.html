What we learned

Current synthesis from the research packet. Exact records and complete source artifacts remain visible below.

Research conclusions

  • Postgres is the default for Actionist-owned transactional data, not a universal donor invariant.
  • Enforce one authoritative owner per table and migration, with tenant identity from the first migration.
  • Use donor stores plus events/read models for intact services and real foreign keys for absorbed code.

What it owns

  • State classification and source of truth
  • Typed data ports
  • Schema and migration ownership
  • Events/read models/files/search
  • Data binding and rollback

Open first-principles questions

  • What operations must v1 data ports support?
  • One DB, schemas, service stores or hybrid per client?
  • How are dual writes prevented?
  • What migration/rollback contract belongs in an assembled release?
