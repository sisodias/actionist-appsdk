Shaan's design principles · 26 Aug

The three principles

P1 · Interstitial retrieval

A nice UI costs millions of tokens from scratch — but if the code exists on GitHub, it's just integration. Query the corpus between build steps, not once upfront. The corpus grows daily.

P2 · Image-gen design front-end

Before any code: generate page concepts, moodboards, design-token candidates as images. Client reacts in seconds per round — "feeling vibes and feels." Only approved directions become code.

P3 · Guide agent, chat → voice

A conversational agent you can message or literally talk to walks the user through the whole build: elicits, presents, narrates, collects approvals. Easiest interface for non-technical users.

Ordering: design decides what, retrieval supplies how — so image rounds precede retrieval, with one twist: the design round is seeded with directions the component library can actually honor. Image-gen proposes, corpus disposes. The guide isn't a fourth step; it's the spine the other two hang off.

Research verdicts · all three lanes complete

Do the principles survive the evidence?

P1 — survives, with two corrections RESEARCHED

  • Gate it, don't always fire it. Iterative retrieve↔generate beats one-shot (RepoCoder, EMNLP'23, +10%), but always-on retrieval hurts — a "will retrieval help here?" self-check gets up to 70% inference speedup with no accuracy loss (Repoformer, ICML'24).
  • Never search "similar code." Naive similar-code injection dropped Pass@1 from 36.5 → 19.6 in a controlled study. Search APIs, contracts, and intent after task decomposition (+20%).
  • Hierarchical granularity (repo→file→AST-block→line), AST-aware ~2–2.5k-char chunks, top-5 evidence packs, hard context budget (median true evidence span: 27 lines).
  • Hybrid index, RRF-fused: lexical/symbol + embeddings + AST/graph + metadata. No single retriever dominates; Sourcegraph moved off embeddings at >100k-repo scale.
  • License gate is mandatory: unlicensed = default copyright = not harvestable; GPL/AGPL reject-by-default; ScanCode over retrieved files and the assembled tree, SPDX output as CI gate.

P2 — works; tokens become the contract RESEARCHED

  • Breadth rounds are seconds-and-cents on fast image models (a 6–10 candidate round ≈ $0.20–0.35, sub-2s generation with palette control, seeds, style-references). Slow high-fidelity models (GPT-Image-class, ~40s/img) run async for text-heavy hero assets — never in the sync loop. Per Shaan 26 Aug: default to GPT/free-tier gens; the matrix is an optimization, not a dependency.
  • Clients approve tokens, not pixels. Vision→IR extracts {color, typography, spacing, radius, shadow, layout} JSON with confidence, quantized to allowed scales — because pixels underdetermine fonts/spacing and even frontier models can't do pixel-perfect (Design2Code).
  • Registry-constrained code output trades a little fidelity for reliability — and is exactly what makes cheap-model implementation viable. Sell "your approved direction, faithfully instantiated within the registry."
  • Image→design-tokens has zero OSS implementations. Most novel piece of the pipeline.

P3 — chat-first, voice as a layer RESEARCHED

  • Precedent: Wix killed its forced questionnaire (Nov 2024). Design = fast default + opt-in "interview me" depth. Never a rigid interview.
  • Elicitation is an open moat: best current models elicit under a third of implicit requirements (ReqElicitGym) — but guided questioning demonstrably works (GPT-4o follow-ups ≥ human quality). Nothing mature exists in OSS.
  • UX law: voice narrates deltas only; screen owns the artifact, diff, and one Approve/Revise control. Approvals are structured state. Silence ≠ approval.
  • Stack: WebRTC either way. OpenAI Realtime = shortest path; LiveKit = extensibility path (Shaan sent Cena livekit in Mar '26; ~$0.10 hosting per 10-min session).

Three lanes independently reported "no public benchmark exists" for their area — the eval harness (golden prompts + validator gates defining "good app" mechanically) is novel IP.

Why vibesdk failed them (and ours won't)

Cloudflare's own hosted instance reproduces the killer bug: backend apps green in sandbox break in production (issue #313); one-click deploys fail on entitlement coupling even on paid plans (#162); setup demands Workers-for-Platforms + cert manager + wildcard domains. Model routing under the MiniMax constraint

Cheap models: elicitation follow-ups, query bundles, bounded adaptation, capped repair, narration — viable because the action space is structured (the literature shows weak models gain most from constrained edits). Rare budgeted frontier calls: archetype selection on ambiguous specs, design→code compilation, escalated repairs.
