## Documentation-quality findings

- The docs are broad and product-aware: they cover not just the extension but workflow semantics, memory, triggers, partner SDK behavior and token economics.
- Some pages contain illustrative dashboard values such as active triggers, fired triggers, success rate and latency. Unless marked as an export, treat these as UI examples.
- Actionist docs have not kept pace with the current `actionist.ai` product/pricing pages. “Private beta,” “coming soon,” and 2025 roadmap language remains publicly visible.
- The partner SDK page is strategically important but incomplete: webhooks are future, the private registry is not inspectable in this public run, and the event/error contract needs a real integration review.
- The token model contains a material per-action pricing mismatch. This should be resolved in writing before any token or unit-economics analysis.
