# Phase 8 convergence gate

Phase 8 is accepted only by artifact evidence, never pane status or callback language.

## Lane artifact contract

| Lane | Required artifacts |
|---|---|
| Universal block framework | `universal-block-framework.md`, `universal-block-contract-delta.json`, `lane-state.json` |
| Local corpus join | `local-corpus-join.jsonl`, `local-corpus-join-report.md`, `overlap-and-dedupe.jsonl`, `lane-state.json` |
| B2B template shelf | `b2b-template-shelf.jsonl`, `b2b-template-shelf-report.md`, `template-contract-v1.json`, `lane-state.json` |
| Repo-to-block mechanics | `repo-to-block-pipeline.md`, `mechanism-and-tool-census.jsonl`, `receipt-schema.json`, `lane-state.json` |
| Composition agent and evals | `composition-agent-architecture.md`, `composition-eval-suite.json`, `synthetic-pilot-plan.md`, `lane-state.json` |

## External Opus input contract

- Lovable clone input requires Markdown report, JSONL census, lane state, source paths/URLs, and explicit license/disposition fields.
- Template input requires Markdown gap report, JSONL seed register, lane state, and exact links back to raw starter lanes and vertical-taxonomy evidence.
- Connector input requires a durable report/register after the active GitHub campaign finishes, with product/provider counts, architecture, licensing, embedded UX, auth/token custody, and adopt/reference/reject dispositions.

## Independent checks

1. All required JSON and JSONL files parse completely and have no blank records.
2. Every `lane-state.json` preserves `research_only=true`, `execution_status=UNEXECUTED`, `admission_status=NOT_ADMITTED`, `admitted_blocks=0`, and parent goal active.
3. Every report is substantive, names its evidence classes, carries source paths or first-party URLs, and preserves falsifiers/unknowns.
4. Cross-lane identifiers are joinable: industries use the canonical 17 IDs; template archetypes map to atoms/blocks; tool mechanisms map to receipt families; composition requirements map to Block Contract fields.
5. Local counts are recomputed from current metadata rather than copied from narrative prose.
6. No lane duplicates the connector, Lovable-clone, or template-gap work without explaining the incremental question.
7. No source clone/copy, authenticated action, source execution, build, benchmark, scan, implementation, deployment, client data use, or block admission occurred.
8. A coordinator contradiction pass compares all five lanes before shared Phase-8 promotion.

The verifier may return PASS with pending lanes in prepromotion mode. That proves coordinator structure and valid artifacts already present; it does not prove Phase 8 completion.
