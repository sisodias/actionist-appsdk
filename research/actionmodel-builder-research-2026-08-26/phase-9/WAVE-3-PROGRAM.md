# Phase 9 Wave 3 — dimension and conversion depth

Wave 2 established 166 immutable target identities and 76 immutable template/local candidate identities. Wave 3 adds repository-specific evidence without treating identity as capability.

## P9-L07 — 166-pair dimension depth

Own `phase-9/wave-3/lanes/07-pair-dimension-depth/outputs/` only.

For each of the 166 resolved Wave-2 target identities, emit all ten canonical repository-specific dimension records: demand/atom fit, workflow behavior, data model, integration surface, UI assembly, agent authority, verification/eval, provenance/rights, runtime/deployment and economics/maintenance. Exact denominator: 1,660 unique pair×dimension cells. Use pinned-revision first-party GitHub metadata, README/manifests/tree evidence where available. Separate direct, inherited, inferred, unknown and blocked. A pair is dimension-complete only if all ten cells meet the programme's declared evidence threshold; identity alone is not completion.

## P9-L08 — competitor ranks 31–60

Own `phase-9/wave-3/lanes/08-competitor-direct-evidence/outputs/` only.

Repeat the strict feature-specific first-party census for deterministic surfaces PS-031 through PS-060 across all 144 canonical features: exactly 4,320 unique cells. Generic product URLs are not direct capability evidence. Every direct claim requires URL, date, precise claim and falsifier. Emit an explicit delta against Phase-9 L02.

## P9-L09 — Stage 2/3 template depth

Own `phase-9/wave-3/lanes/09-local-stage2-stage3/outputs/` only.

For all 76 strict Stage-0 candidates, inspect only pinned-revision public GitHub metadata, trees, READMEs and dependency manifests through API/raw endpoints. Classify source shape and dependency closure with explicit completeness limits. Emit one Stage-2 shape receipt and one Stage-3 dependency receipt per candidate, plus gaps. No clone, package install, source execution or build. Rights metadata is not clearance; no admission.

## Required packet

Each lane writes machine-readable ledgers, source receipts, a report, canonical lane-state JSON, full hashes and a no-bytecode verifier. Parent remains active; promotion remains false.
