Run ID: `2026-08-27-sprint-2-opus`

## Objective

Convert the verified-with-holds Sprint 1 evidence into a coherent modular assembly framework. This sprint is not another broad company/repository census. It must define the contracts, algorithms, boundaries and falsifiable worked traces required to turn heterogeneous source into composable Actionist modules.

## Primary architectural question

How can Actionist reuse complete services, embedded modules, transplanted subsystems, extracted packages, adapters, generated patterns, templates and custom deltas inside one maintainable client application without forcing every source into one database, runtime or UI architecture?
