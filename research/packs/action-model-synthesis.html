03 / Contradiction ledger

Where synthesis refused to smooth the evidence

Contradictions are preserved as work items.

Platform tracker mismatch

status.json reports one blocked dossier and 34 held/rejected claim groups. The pre-repair CURRENT.md reported zero blocked dossiers and 25 groups. Checkpoint-009 repaired the human-readable tracker; aggregate recomputation remains explicit.

Resolution

Use the structured one-blocker posture until a future checkpoint independently recomputes the aggregate.

Vertical crosswalk mismatch

Earlier metadata declared 40 covered use cases / 23 ideas / 26 remaining, while the corrected inventory is 39 / 24 / 27. Synthesis kept the correction rather than silently adopting the broader numbers.

Resolution

Do not promote any catalogue edge to authenticated or implemented status until the source JSON is repaired.

Documented vs live

Vertical cards and platform dossiers contain useful first-party descriptions, but no credentialed run proved arbitrary GUI operation plus approval, verification, and recovery.

Resolution

“Documented workflow” and “authenticated live” remain separate fields everywhere.

Buy vs build

Design notes describe a scoped builder as feasible; the evidence packets show no runtime implementation or end-to-end release.

Resolution

Treat feasibility as a design hypothesis; require a pinned block and full gate receipts before calling it a build.

04 / Authorization rule

What must be true before implementation

Copied from the decision logic, not invented for this page.

No real Block Contract pilot until one candidate has source + license, adaptation, valid contract, isolated build, smoke/visual proof, owner, and rollback.

Source

Pinned commit, license/provenance, dependency and asset receipt.

Execution

Adaptation, deterministic build, browser smoke, write denial, screenshot baseline.

Ownership

Named owner, rollback path, data boundary, and final verdict.

Current queue: preserve the 39-use-case/24-idea correction, run the cross-lane contradiction pass, and keep Horizon/P-010/P-014 held until their ladders are complete.
