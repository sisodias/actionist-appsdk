What is actually proven

Each reviewed disposition has a source path, canonical repository URL, reason, and next gate.

That is a useful evidence discipline. It is not the same as a build receipt. No candidate checkout, build, browser run, screenshot baseline, license scan, owner, or rollback manifest was completed for the pilot.

Why 389 is still light

The corpus was reused from an existing merged sweep, not restarted. The external 850k-repository data plane and local catalogue database were not mounted in this run. The next sweep should be per industry and capability, not one undifferentiated “AI builder” query.

Interpretation: 389 is a reliable current funnel count, not a claim about all useful GitHub code.

04 / Admission plan

The seven gates the pilot never reached

Cluster-007 is a plan and preflight, not execution.

G1

Source + license provenance

Pin the commit, record license and obligations, scan source/dependencies/assets, and preserve the receipt.

G2

Extraction + adaptation

Record what is copied, wrapped, transformed, or discarded; map ownership and token/registry slots.

G3

Deterministic build

Install from the pinned source, run typecheck/build/tests, and capture the output.

G4

Browser smoke + write denial

Prove the candidate renders and cannot create unintended external side effects in the fixture environment.

G5

Screenshot baseline

Compare the adapted block against the approved visual contract, not just “it loaded.”

G6

Owner + rollback

Name the accountable owner, rollback path, data boundary, and recovery behavior before admission.

G7 / final verdict

No gate receipt, no admission.

The plan explicitly stops before the final verdict when prerequisites are missing. That is why the research produced zero admitted blocks without being “empty.”
